# my-smg 学习与实施计划

`my-smg` 是教学用模型网关：从同步轮询器逐步演进到支持并发、流式转发和故障处理的小项目。

计划分为 **主线 12 阶段 + 扩展专题**，另设阶段 0 完成工程准备。每个阶段都有可运行版本、验收标准和原仓库对照。当前文档是计划，不代表功能已经实现。

## 学习路线

```text
阶段 0～3             阶段 4～6             阶段 7～9
同步 Rust 基础  --->  配置与 HTTP 转发 ---> 并发与故障处理
                                              |
                                              v
扩展专题        <---  阶段 10～12
协议与生态集成        熔断 / 流式 / 观测 / 停机
```

| 里程碑 | 完成标志 |
|---|---|
| M1：同步轮询器 | 独立写出轮询器，能解释所有权和借用 |
| M2：可运行网关 | 启动两个假节点，用 `curl` 验证请求转发 |
| M3：并发与可靠性 | 节点变化、超时、重试和取消行为可验证 |
| M4：主线完成 | 支持流式响应、故障控制、观测和优雅停机 |
