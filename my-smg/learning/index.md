# my-smg 学习与实施计划

`my-smg` 是教学用模型网关：从同步轮询器逐步演进到支持并发、流式转发和故障处理的小项目。

## 当前任务：阶段 12——优雅停机

本轮已完成日志与基础指标。指标口径如下：

| 指标 | 口径 |
|---|---|
| 请求总数 | 进入请求中间件时计数，排除 /metrics |
| HTTP 错误与响应准备耗时 | 响应头准备好时，按状态码记录 4xx/5xx；耗时包含前面的排队和上游等待 |
| 流式结束与正文耗时 | 正文流销毁时记录完成、失败或取消；耗时包含背压等待 |
| 耗时累计值 | 分别配合响应就绪数、流式结束数计算平均值；两组样本范围不同，不直接相加 |

响应头 200 不代表流式正文完整；HTTP 错误与正文失败也不能直接相加作为失败请求数。
/metrics 返回 JSON 教学快照，不包含直方图或分位数；响应就绪不等于客户端已经消费正文。

剩余工作：

1. 接收停机信号，停止接收新连接，并停止、等待后台健康检查任务。
2. 等待已有普通/流式请求结束；到达截止时间后终止进程，避免无限等待。
3. 验证空闲停机、在途请求完成、长流超过期限及后台任务清理。
