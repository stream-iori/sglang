# 扩展专题

[返回学习入口](./index.md) · [上一篇：主线实施计划](./02-mainline.md) · [下一篇：原仓库对照](./04-source-map.md)

主线完成后，每个专题独立实施和验收，按兴趣选择顺序。涉及真实外部系统的部分，先模拟，再接入。

| 专题 | 实施内容 | 学习重点 | 完成标志 |
|---|---|---|---|
| **更多负载均衡策略** | 随机、二选一、加权/分桶选择 | 算法、数据结构、可重复随机测试 | 固定输入下能验证选择行为和分布 |
| **哈希与缓存感知** | 一致性哈希；字符串前缀匹配；简化缓存淘汰 | 树、哈希、递归、内存取舍 | 节点增删后测量映射变化；相同前缀倾向同节点 |
| **多模型路由** | 请求按模型分组；每组配置独立策略 | 注册表、组合、配置建模 | 不同模型进入各自节点池 |
| **PD 路由** | 模拟 prefill 产出上下文引用，再交给 decode | 多步骤异步流程、错误传播、清理 | 任一阶段失败都可定位，不遗留任务 |
| **任务队列与工作流** | 注册节点分成校验、探测、入库、激活；查询任务状态 | channel、状态迁移、幂等处理 | 重复注册行为明确；失败步骤可追踪 |
| **服务发现** | 本地事件源模拟加入/退出；随后接 Kubernetes | 外部接口抽象、事件流、重连 | 初始同步和后续事件均更新节点池 |
| **gRPC** | 定义一个最小模型服务，接入已有路由逻辑 | protobuf、代码生成、传输层抽象 | 同一业务入口可访问 HTTP 和 gRPC 节点 |
| **分词与增量解析** | 简单分词接口；解析跨分段的 reasoning/tool 标记 | UTF-8、字符串切片、缓冲、状态机 | 中文、半个标记、多个分段都能正确处理 |
| **会话存储** | 内存存储和 SQLite 两种实现 | 存储 trait、连接池、事务 | 切换实现不修改路由逻辑 |
| **鉴权与 TLS** | API key 校验；本地 TLS，再练习 mTLS | middleware、请求上下文、配置集成 | 合法请求通过；缺失或错误凭证被拒绝 |
| **工具调用与 MCP** | 先实现一个本地工具，再接一个 MCP 服务 | 协议适配、异步调用、边界错误 | 工具成功、超时和失败均有确定行为 |
| **WASM 扩展** | 插件修改一个请求字段 | 插件接口、宿主与插件边界 | 插件可加载，失败时按既定规则处理 |
| **节点间同步** | 两个网关同步简化节点信息 | 版本、幂等、最终一致性 | 重复事件不重复注册，断开重连能恢复 |
| **Python 绑定** | 暴露一个配置或节点选择函数 | FFI、类型转换、跨语言错误 | Python 能调用，错误可正常转换 |
| **性能分析** | 比较策略开销、锁竞争、流式内存 | benchmark、profiling、分配与复制 | 有测量结果，再做一次有依据的优化 |

## 范围与依赖

| 约定 | 说明 |
|---|---|
| 概念覆盖 | 模拟 PD 或简单分词不等于复现真实推理行为 |
| 教学选型 | SQLite 是迷你版的教学选型，不代表原项目使用相同存储 |
| 推荐先后 | 多模型路由后做 PD；增量解析后做工具调用；本地节点管理后做服务发现与同步 |
| 外部依赖 | 在对应专题实施时确认版本、接口和运行条件 |
| 新协议 | 明确支持的最小字段和行为，再逐步增加兼容范围 |

每个专题沿用[每课流程与记录模板](./05-workflow.md)，无需一次完成全部专题。
