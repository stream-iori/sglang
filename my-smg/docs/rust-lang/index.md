# 从 my-smg 学 Rust

**先按当前任务读最少概念，卡住时回查，实现并验收后再读完整调用链。**

这里是 [learning 实施课程](../../learning/index.md)的配套材料，不要求从头通读，也不代替学习者亲手实现与行为验收。

## 选择入口

|---|---|

## 学习台阶

```text
阶段 0    工程、模块、构建和测试
   ↓
阶段 1～2 节点和值 → 拥有与借用 → Vec/切片 → Option/匹配 → 同步轮询
   ↓
阶段 3～4 策略抽象 → 配置与错误
   ↓
阶段 5～6 Future 与 HTTP 接口
   ↓
阶段 7～9 共享状态 → 后台任务 → 超时与重试
   ↓
阶段 10～12 熔断/限流/排队 → 流式 → 观测与停机
```

这是课程顺序，不是要求通读全部文章的依赖图。后续阶段的材料缺口在[阶段清单](stage-reading.md)列出，不把已有熔断或非流式代码当作后续阶段已经完成。

## 怎样读一篇

| 位置 | 阅读方式 |
|---|---|
| 前置 | 只补所需基础部分，不递归通读其延伸内容 |
| 基础解释与基础自查 | 判断类型、拥有者、修改权限和结果 |
| 标注阶段的项目应用 | 到对应阶段再读，源码入口不等于当前任务要理解完整实现 |
| 综合题和延伸 | 按需选读，不当成早期任务的验收 |

源码摘录、历史同步接口、独立示意分别标注；省略实现体的片段不能当成完整程序。
每个知识保留一个主要讲解位置，其他文章链接过去；Maven、JPMS、Netty、PECS 都是可选对照。
